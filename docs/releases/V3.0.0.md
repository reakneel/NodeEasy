# NodeEasy V3.0.0

## Release status

**V3.0.0 — Architecture and runnable foundation release**

NodeEasy V3.0.0 establishes the local-first node data center foundation:

`collect → normalize → deduplicate → test → score → export/share`

## Included

- Rust workspace and canonical node domain model
- SQLite persistence and migrations
- HTTP subscription source ingestion
- URI/Base64/Clash YAML/JSON parsing foundation
- normalization, fingerprinting and deduplication
- SSRF protection and source size limits
- Axum REST API
- asynchronous jobs and WebSocket event bus
- Vue 3 + Vite dashboard
- bounded TCP node testing
- deterministic 0–100 scoring foundation
- safe node catalog JSON export
- QR deep-link sharing target
- Tauri 2 desktop shell
- Windows x64/ARM64 release workflow

## Deliberate V3.0 boundaries

V3.0 does **not** claim to provide full credential-bearing proxy-client export or a complete measurement engine.

- TLS/HTTP/download/stability probes are V3.1 work.
- Mihomo/Clash and sing-box credential-bearing exporters are V3.1 work.
- A secure secret store is required before persisting or exporting sensitive credentials.
- Proxy engines remain adapters; NodeEasy core does not become a proxy client.

## Security

Remote source fetching is restricted to HTTP(S) by default and protects against requests to loopback/private/link-local destinations. Public/free nodes are untrusted and must not be used for sensitive traffic.
